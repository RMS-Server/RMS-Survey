# RMS Survey Frontend

Vue 3 + Vite + TypeScript + Ant Design Vue frontend for the survey system.

## Development

```bash
npm install
npm run dev
```

## Build

```bash
npm run build
```

The build output will be placed in `../server-go/static/`.

## Features

- User authentication (login/register)
- Survey management (CRUD)
- Survey editor with drag-and-drop
- 5 question types: radio, checkbox, fill-in-blank, dropdown, rating
- Public survey filling page
- Answer management and export
- User/role management
